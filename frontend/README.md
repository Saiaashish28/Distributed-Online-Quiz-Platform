# QuizSphere frontend

React + TypeScript + Vite + Tailwind CSS client for QuizSphere. See the [project README](../README.md) for setup, environment variables and deployment.

```bash
cp .env.example .env.local   # VITE_API_BASE_URL, VITE_WS_BASE_URL
npm install
npm run dev                  # http://localhost:5173
npm run build                # type-check + production build into dist/
```
